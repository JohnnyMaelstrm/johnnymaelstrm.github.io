# Hayabusa

<img src="/assets/Hayabusa/hayabusa0.png" alt="Hayabusa Banner" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<p class="project-intro">
If you're doing Windows forensics or incident response related-CTF challenges, you've probably heard about <span class="highlight">Hayabusa</span>, that handy open-source tool that makes digging through Windows event logs actually bearable. It's like having a security analyst buddy who never sleeps, constantly sifting through logs looking for suspicious stuff.
</p>

<p>
It's free and open source, so you can grab it from their GitHub and start using it today: <a href="https://github.com/Yamato-Security/hayabusa" target="_blank" style="color: #b6854e;">Yamato-Security/hayabusa</a>
</p>

<p>
Here are the commands I find useful - the ones that actually save me time when I'm knee-deep in event logs:
</p>

<h3>Simple check</h3>

<div class="command-block">
hayabusa log-metrics -f "filename".evtx
</div>

Provides basic file metadata and event statistics - perfect for initial assessment.

</div>

<img src="/assets/Hayabusa/hayabusa1.png" alt="Log Metrics" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<h3>Event ID analysis</h3>

<div class="command-block">
hayabusa eid-metrics -f "filename".evtx
</div>

Shows the most common <span class="highlight">Event IDs</span> and their counts - great for identifying normal vs. abnormal activity patterns.

</div>

<img src="/assets/Hayabusa/hayabusa2.png" alt="Event ID Metrics" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<h3>Basic timeline creation</h3>

<div class="command-block">
hayabusa csv-timeline -f "filename".evtx -o timeline.csv
</div>

Creates a basic forensic timeline in <span class="highlight">CSV format</span> that's easy to open in Excel or other analysis tools.

</div>

<img src="/assets/Hayabusa/hayabusa3.png" alt="CSV Timeline" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<h3>Logon activity summary</h3>

<div class="command-block">
hayabusa logon-summary -f "filename".evtx
</div>

Provides an overview of successful and failed logons - essential for detecting <span class="highlight">brute force attacks</span> or unauthorized access.

</div>

<img src="/assets/Hayabusa/hayabusa5.png" alt="Logon Summary" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<h3>Search for specific keywords</h3>

<div class="command-block">
hayabusa search -f "filename".evtx -k "mimikatz"
</div>

Searches for specific threat indicators or suspicious tools in the event logs.

</div>

<img src="/assets/Hayabusa/hayabusa6.png" alt="Keyword Search" style="max-width: 100%; height: auto; border-radius: 8px; margin: 1.5rem 0;">

<div class="project-page">

<h3>Quick minimal analysis</h3>

<div class="command-block">
hayabusa csv-timeline -f "filename".evtx -p minimal -o quick_scan.csv
</div>

Perfect for rapid assessments when you need quick results without noise.

<h3>Identify critical systems</h3>

<div class="command-block">
hayabusa config-critical-systems -f "filename".evtx
</div>

Automatically identifies <span class="highlight">domain controllers</span>, <span class="highlight">file servers</span>, and other critical infrastructure.

<div class="tip-box">
<h2>Practical Workflow Tips</h2>

<ol>
<li><strong>Start with metrics</strong>: Always begin with <code>log-metrics</code> and <code>eid-metrics</code> to understand your data</li>
<li><strong>Use profiles wisely</strong>: Choose <code>minimal</code> for quick scans, <code>detailed</code> for comprehensive analysis</li>
<li><strong>Filter by level</strong>: Use <code>-l high,critical</code> to reduce noise in large datasets</li>
<li><strong>Export to CSV</strong>: Always save your results for further analysis in spreadsheet tools</li>
<li><strong>Combine with other tools</strong>: Use Hayabusa outputs as input for timeline analysis in other forensic tools, for example Zimmermann Tools</li>
</ol>
</div>

<p>
Remember: Hayabusa is particularly powerful for detecting <span class="highlight">lateral movement</span>, <span class="highlight">persistence mechanisms</span>, and <span class="highlight">privilege escalation</span> techniques commonly used by attackers.
</p>
