  <h1>Custom C2 Infrastructure</h1>

  <p>For my Bachelor's thesis, I focused on the practical implementation of a Command and Control (C2) infrastructure to understand modern adversary tradecraft. I selected the <strong>Mythic C2</strong> framework for its modularity and deployed it on a Kali Linux environment using Docker containers.</p>

  <p>The project involved simulating full attack chains against both Windows and Linux targets (Parrot OS), utilizing agents like <strong>Apollo</strong> and <strong>Poseidon</strong> to execute post-exploitation tasks while maintaining operational security (OpSec).</p>
  
  <p><strong>Status:</strong> Completed (Grade: 5/5)<br>
  <strong>Focus:</strong> Red Teaming, Fileless Malware, Traffic Analysis</p>

  <h2>Technical Deep Dive: Linux Evasion</h2>

  <h3>1. Payload Obfuscation (Bincrypter)</h3>
  <p>To demonstrate evasion techniques against Linux targets, I moved beyond standard payloads. I utilized <a href="https://github.com/hackerschoice/bincrypter" target="_blank">Bincrypter</a> to obfuscate the <strong>Poseidon</strong> agent (an ELF binary).</p>

  <p align="center">
    <img src="{{ '/assets/Thesis/image_33.png' | relative_url }}" alt="Bincrypter Logic" style="max-width:90%; height:auto;" />
  </p>

  <p>The screenshot above shows the obfuscation process. Bincrypter compresses and encrypts the original binary into a shell script. In my testing, this effectively masked the executable from static analysis tools, as the payload appeared as a high-entropy data blob rather than a known malicious file format.</p>

  <h3>2. Fileless Execution (memfd_create)</h3>
  <p>A key objective of the thesis was to achieve persistence without leaving forensic artifacts on the disk. The obfuscated payload leveraged the Linux syscall <code>memfd_create</code>.</p>

  <p align="center">
    <img src="{{ '/assets/Thesis/image_34.png' | relative_url }}" alt="Fileless Execution Proof" />
  </p>

  <p><strong>The Execution Mechanics:</strong></p>
  <ul>
    <li><strong>Allocation:</strong> The script allocates an anonymous file descriptor in RAM.</li>
    <li><strong>Decryption:</strong> The encrypted payload is decrypted directly into this memory buffer.</li>
    <li><strong>Execution:</strong> The payload is executed via <code>execve</code> from the file descriptor.</li>
  </ul>

  <p>As seen in the process list (<code>ps aux</code>) in the image above, the agent runs successfully as <code>/memfd: (deleted)</code>. This confirms that the binary exists only in volatile memory, bypassing standard disk-based antivirus scanning and complicating forensic recovery.</p>

  <h2>Conclusion</h2>
  
  <p>This project demonstrated that building a robust C2 infrastructure requires more than just server setup; it demands a deep understanding of network protocols and operating system internals. By analyzing the traffic in Wireshark, I was able to verify the effectiveness of SSL-encrypted channels (HTTPS) versus unencrypted HTTP traffic.</p>

  <p>The thesis received the highest possible grade (5/5). It bridged the gap between theoretical knowledge and practical Red Teaming, particularly regarding the use of advanced evasion techniques like fileless execution.</p>
